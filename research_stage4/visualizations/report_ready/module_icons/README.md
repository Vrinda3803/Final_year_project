# Lucid module icons

These original vector icons were drawn for the MMASD activity-recognition architecture. They use transparent backgrounds and a consistent navy, blue, teal, and gold line style. Each SVG is 128 × 128 and can be resized without losing sharpness.

| File | Suggested module |
|---|---|
| `dataset.svg` | Dataset (MMASD) |
| `pose_sequence.svg` | Input representation / skeleton sequence |
| `data_preparation.svg` | Data preparation and preprocessing |
| `anatomical_graph.svg` | BODY_25 anatomical graph |
| `bilateral_connections.svg` | Bilateral edge learner |
| `joint_reliability.svg` | Joint reliability estimation |
| `temporal_attention.svg` | Temporal self-attention |
| `classifier.svg` | Classification head |
| `activity_output.svg` | Predicted activity output |

Use only the icons needed for the diagram. Keeping the same icon style and a modest size will help the report figure remain readable.
