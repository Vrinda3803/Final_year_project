## 2. Cross-Validation & Data Partitioning Protocol

### 2.1 Identical Fold Alignment
To ensure strict, scientific comparability with historical experiments (E0–E9 and the RBF Kernel SVM), all Stage 4 models use the **exact same 5-fold GroupKFold assignments** generated by `create_subject_independent_folds(data["groups"], n_folds=5, seed=42)`:
- **Total Samples:** 1,374 recordings
- **Cohorts:** 32 unique recording cohorts
- **Cohort Overlap across Folds:** Strictly 0
- **Fold 0:** 276 test recordings (cohorts: `40143`, `20594`, `40163`, `40323`, `41263`, `41713`)
- **Fold 1:** 276 test recordings (cohorts: `40023`, `20613`, `40074`, `40344`, `41323`, `41463`)
- **Fold 2:** 277 test recordings (cohorts: `20583`, `40404`, `40683`, `40794`, `41203`, `41513`)
- **Fold 3:** 275 test recordings (cohorts: `40493`, `40534`, `40813`, `40843`, `40913`, `41343`, `41443`)
- **Fold 4:** 270 test recordings (cohorts: `20564`, `20626`, `40933`, `41063`, `41133`, `41143`, `41533`)

### 2.2 Strict Zero-Leakage Data Handling
1. **Fit / Validation / Test Partitioning:** For each fold, outer training data (approx. 1,098 clips) is partitioned into a fit set (82%) and an internal validation set (18%) grouped strictly by cohort.
2. **Feature Normalization:** Mean ($\mu$) and standard deviation ($\sigma$) are fitted exclusively on the fit partition. Test sequences are normalized using fit statistics and clipped to $[-8.0, 8.0]$.
3. **Kinematic Velocity Priors:** Empirical velocity dispersions ($\sigma_{v,i}$) for the 25 joints are calculated strictly using fit partition coordinates where detection confidence $c > 0.5$.
4. **Post-Hoc Probability Calibration:** Platt temperature scaling parameters ($T_{\text{temp}}$) are optimized strictly on validation fold logits via negative log-likelihood minimization. Test logits are evaluated using the fitted temperature with zero parameter leakage.

## 3. Training Hyperparameters & Optimization Schedule

| Hyperparameter | Value | Rationale |
|---|---|---|
| **Batch Size** | 32 | Balanced gradient estimate for small-sample stability |
| **Max Epochs** | 35 | Sufficient for convergence with early stopping |
| **Optimizer** | AdamW | Decoupled weight decay prevents attention over-smoothing |
| **Base Learning Rate** | $1.0 \times 10^{-3}$ | Optimal learning rate identified in Stage 1 & 2 |
| **Weight Decay** | $1.0 \times 10^{-4}$ | $L_2$ regularization on attention and projection weights |
| **LR Scheduler** | CosineAnnealingLR | $T_{\text{max}} = 35, \, \eta_{\text{min}} = 1.0 \times 10^{-5}$ |
| **Gradient Clipping** | Max Norm = 1.0 | Prevents explosive gradients during spatial attention |
| **Early Stopping Metric**| Validation Macro-F1 | Evaluates balanced class performance rather than skewed accuracy |
| **Early Stopping Patience**| 10 epochs | Prevents premature termination on plateau folds |
| **Dropout Rate** | 0.25 | Applied on spatial attention, temporal attention, and MLP |

## 4. Loss Objectives & Regularization

### 4.1 Class-Balanced Focal Classification Loss
To counter the 5.7:1 class imbalance between Drumming (343 clips) and Tree Pose (60 clips), all models employ class-balanced Focal Loss:
$$\mathcal{L}_{\text{Focal}}(\mathbf{p}, y) = -\alpha_y (1 - p_y)^\gamma \log(p_y)$$
where:
- $\gamma = 1.2$ (focusing parameter down-weighting easy samples).
- $\alpha_y = \frac{1 / N_y}{\sum_{c=1}^{10} 1 / N_c}$ (inverse class frequency weights computed strictly from fit fold labels).

### 4.2 Confusable-Pair Margin Regularization (A9 Only)
For ablation A9, an angular cosine margin loss is added to penalize semantic collapse between confusable exercise twins:
$$\mathcal{L}_{\text{CPM}} = \frac{1}{|\mathcal{B}_{\text{conf}}|} \sum_{(i, j) \in \mathcal{B}_{\text{conf}}} \max(0, \cos(\mathbf{z}_i, \mathbf{z}_j) - m)$$
where $m = 0.5$, $\lambda = 0.25$, and $\mathcal{B}_{\text{conf}}$ denotes sample pairs from $\{(\text{dr}, \text{sac}), (\text{ms}, \text{mfs}), (\text{sq}, \text{as})\}$.

## 5. Specification of the 10 Ablation Configurations (A0 to A9)

| Exp ID | Model Code | Core Scientific Objective | Implementation Specifics |
|:---:|---|---|---|
| **A0** | `e2_fixed_topo_repro` | Replicate E2 fixed bilateral topology as reference baseline | Static boolean mask on bone + E2 relational edges; static geometric mean reliability gate |
| **A1** | `rcdb_no_rel_gate` | Test dynamic relationship learning without reliability gating | Dynamic bilateral edge learner active; $q_{uv}(t) = 1.0$ (no confidence attenuation) |
| **A2** | `rcdb_rel_only_no_dyn` | Test reliability conditioning without dynamic movement context | Dynamic edge learner bypassed ($a_{uv}=1.0$); edge modulated solely by $q_{uv}(t) = \sqrt{r_u r_v}$ |
| **A3** | `rcdb_full_main` | **Main Proposed Model:** Dynamic learning + reliability gating + temporal smoothing | Full RCDB-STGT: dynamic MLP + 1D temporal conv ($K=5$) + multiplicative gate $q_{uv}(t) \cdot a_{uv}(t)$ |
| **A4** | `rcdb_no_temp_smooth` | Test contribution of temporal edge dynamics | A3 architecture with 1D temporal convolution disabled ($a_{uv}(t)$ computed purely per-frame) |
| **A5** | `rcdb_with_phase` | Test whether harmonic phase velocity stream adds value to dynamic graph | A3 architecture + projected harmonic phase difference stream $\Delta \phi_t$ |
| **A6** | `rcdb_wrist_only` | Test whether wrist-only bilateral communication is sufficient | A3 architecture with $\mathcal{P}_{\text{bi}} = \{(4, 7)\}$ (RWrist <-> LWrist only) |
| **A7** | `rcdb_multi_pair` | Test broader bilateral limb topology across upper and lower body | A3 architecture with wrists $(4,7)$, ankles $(11,14)$, elbows $(3,6)$, knees $(10,13)$, hips $(9,12)$ |
| **A8** | `rcdb_input_rel_only` | Test explicit multiplicative gate vs. reliability as MLP feature only | A3 architecture with $r_u, r_v$ fed to edge MLP, but external multiplication $q_{uv}(t)$ removed |
| **A9** | `rcdb_with_margin` | Test whether confusable-pair margin loss improves or destabilizes dynamic graph | A3 architecture trained with joint loss: $\mathcal{L}_{\text{Focal}} + 0.25 \cdot \mathcal{L}_{\text{CPM}}$ |

## 6. Output Logging & Metric Preservation

Every ablation experiment saves:
1. **Model Checkpoints:** Saved per fold in `research_stage4/checkpoints/<exp_name>/fold_<k>.pt` containing model weights, calibrated temperature $T_{\text{temp}}$, fold accuracy, and Macro-F1.
2. **Out-of-Fold Prediction CSV:** Saved in `research_stage4/predictions/<exp_name>_oof.csv` with columns:
   `clip, group, fold, y_true, y_pred, confidence, prob_as, prob_bs, ..., prob_tw`
3. **JSON Summary Metrics:** Saved in `research_stage4/metrics/<exp_name>_summary.json` recording mean fold accuracy, standard deviation, pooled OOF accuracy, pooled Macro-F1, mean ECE, per-class F1, and training duration.
